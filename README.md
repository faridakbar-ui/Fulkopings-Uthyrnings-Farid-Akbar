# Fulköpings Uthyrnings AB
Jag har byggt REST API med Java och Spring Boot.

API:et hanterar personer och saker som hyrs ut.

## Funktioner

* CRUD för personer och saker.
* Koppla personer till saker.
* Validering och felhantering.
* H2-databas.

## Starta

Starta projektet i IntelliJ.

När man raderar person eller sak tas kopplingen bort först ifall de är kopplade.

Har testat med postman

API: `http://localhost:5500`
